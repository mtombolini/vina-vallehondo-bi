# Notebooks

Usa notebooks numerados para exploración y validación, por ejemplo:

1. `01_profiling.ipynb`: perfilado de fuentes y hallazgos de calidad.
2. `02_hallazgos_mandato.ipynb`: cifras medidas del mandato y de la bitácora de supuestos.
3. `03_modelado_estrella.ipynb`: modelo estrella de ventas con conversión a pesos.
4. `04_metrica_sensibilidad.ipynb`: ficha de la métrica y sensibilidad a la fecha del dólar (Sección D).
5. `05_evidencia_recomendacion.ipynb`: visualizaciones, caso de negocio, recomendación y cobertura (Sección E).

Cuando una transformación esté validada, muévela al ETL en `src/vina_vallehondo_bi/etl/`. No uses el notebook como proceso de refresco del tablero.
